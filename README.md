## 結構

```
#/                       旅程庫首頁（所有旅程的卡片）
#/<旅程id>/home          那一趟的首頁
#/<旅程id>/itinerary     行程規劃
#/<旅程id>/attractions   景點介紹
#/<旅程id>/food          美食紀錄
#/<旅程id>/phrases       點餐卡
#/<旅程id>/prep          行前準備
#/<旅程id>/map           地圖導航
```

每一趟都在 `defaultData.trips` 裡，彼此獨立。網址可以直接分享到某一頁。

## 怎麼加新旅程

1. 右上角「管理」登入
2.「＋ 新增旅程」，輸入名稱
3.「旅程設定」填日期、簡介，並**勾選這趟要開哪些分頁**
   （用不到的分頁就關掉 —— 上一趟的檢討是「隱藏功能太多」）
4. 其他分頁照常編輯
5. 最後按「📥 匯出更新檔」才會存回 GitHub

## 注意

- 內容是從 localStorage 讀的。看到舊內容時，按頁尾的「🔄 強制更新」，或網址加 `?reset=1`
- 匯出會把**整個旅程庫**一起寫回檔案，不是只有當下那一趟
- Token 存在瀏覽器 localStorage，不會出現在原始碼裡
