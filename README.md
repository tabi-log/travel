# 旅行紀錄 tabi-log

每一趟旅程是一條路線，每一天是一個站。

🔗 網站：https://tabi-log.github.io/travel/

## 福岡之旅 2026

- **日期**：2026.09.29 – 10.04（5夜6天）
- **人數**：8 人同行
- **路線**：博多 → 由布院 → 太宰府 → 八女 → 藥院
- **住宿**：GRAND BASE Hakata（福岡市博多區奈良屋町 8-12）

## 網站內容

- 旅程總覽：全程錨點看板＋6 天路線
- 每日看板：時間表、今天的重點、交通方式與費用
- 景點與店家：62 個地點，依區域分類，附 Google 地圖連結與照片
- 手機與電腦自動切換排版，手機有底部分頁列

## 檔案說明

- `index.html`：網站頁面與版型
- `data.js`：行程、交通、地點資料（要改行程內容改這裡）
- `photos/`：網站用到的照片（`f` 開頭是大圖，`t` 開頭是縮圖）
